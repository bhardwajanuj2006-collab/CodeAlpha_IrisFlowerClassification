Iris Flower Classification 🌸
About the Project

This is my Iris Flower Classification project, completed as part of my CodeAlpha Data Science Internship.

The project uses machine learning to predict the species of an Iris flower based on its measurements.

Dataset

The project uses four features:

Sepal Length
Sepal Width
Petal Length
Petal Width

The three flower species are:

Iris Setosa
Iris Versicolor
Iris Virginica
